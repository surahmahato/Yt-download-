# YT Download - Fast & Secure Video Downloader

[![Android](https://img.shields.io/badge/Platform-Android-green.svg)](https://developer.android.com)
[![Jetpack Compose](https://img.shields.io/badge/UI-Jetpack%20Compose-blue.svg)](https://developer.android.com/jetpack/compose)
[![Material 3](https://img.shields.io/badge/Design-Material%203-purple.svg)](https://m3.material.io)

**YT Download** is an Android application designed for high-speed media fetching. It provides direct, one-tap support for:
- 🎬 **YT video download** (1080p Full HD, 720p HD, 480p SD, and MP3 audio)
- 📱 **TikTok video download** (Fast water-free audio and video downloads)
- 📸 **Instagram video download** (Reels, stories, and post videos)

---

## 🌟 Key Features

- **Direct Phone Gallery Integration**: Automatically saves and indexes media into your device's native `MediaStore` (`Movies/YT_Download`), making videos immediately visible in Google Photos, Samsung Gallery, and native media players.
- **Multiple Resolution & Format Selection**: Choose between 1080p, 720p, 480p, and extracted audio (MP3).
- **Active Download Manager**: Live progress tracking showing percentage, downloaded bytes, total size, and download speed (KB/s).
- **Native Gallery Shortcut**: Tap **"Open in Gallery"** immediately after download or browse downloaded files in the built-in library.
- **In-App Media Player & Social Sharing**: Preview your downloaded videos with playback controls and share directly via social apps.

## 🚀 Getting Started

### Prerequisites
- Android Studio Ladybug / Koala or newer
- JDK 17 or higher
- Android SDK 24+

### Building the Project
```bash
# Clone the repository
git clone https://github.com/your-username/yt-download.git

# Open the directory
cd yt-download

# Build the debug APK
./gradlew assembleDebug
```
The compiled APK will be located at `app/build/outputs/apk/debug/app-debug.apk`.

## 🌐 Deploy as a Website on Render.com

This project includes a complete web application edition ready to deploy live on **Render (render.com)**.

### Deploy on Render:
1. **Option A: Deploy as a Static Site (Recommended & Free)**
   - Sign in to [dashboard.render.com](https://dashboard.render.com/) and click **New +** > **Static Site**.
   - Connect your GitHub repository.
   - **Build Command:** (leave empty or `npm run build`)
   - **Publish Directory:** `public` (or `.`)
   - Click **Create Static Site**.

2. **Option B: Deploy as a Web Service (Node.js)**
   - Click **New +** > **Web Service**.
   - Connect your GitHub repository.
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - Click **Create Web Service**.
